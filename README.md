## 这是什么

一个网页。三根柱子，六十四个盘子，从 A 柱搬到 C 柱。

规则很老，老到 1883 年就被写成了传说：婆罗门神庙里有六十四片金盘，僧侣们日夜不停地搬运，当最后一片金盘落定，世界将在一声霹雳中化为尘埃。

传说里没有写的是：**他们搬完需要 5849 亿年。**

所以这个页面做的事情很简单。它不模拟，不预测，不估算。它只是握着一只时钟，每秒往前走一步，认真地数给你看。

## 关于那串数字

| | |
|---|---|
| 最少步数 | 2⁶⁴ − 1 = 18,446,744,073,709,551,615 |
| 节奏 | 每秒一步 |
| 全部走完 | **约 5849 亿年** |
| 第一步 | **2026 年 10 月 24 日 00:00:00 UTC**（程序员日 1024） |
| 第 64 片金盘第一次移动 | 第 2⁶³ 秒之后，**约 2923 亿年** |

给这几个数字找几个参照物：

- 宇宙现在的年龄，约 138 亿年。走完这一局，要**四十二个宇宙**。
- 太阳的寿命还剩约 50 亿年。它熄灭的时候，这局棋大概走完了**百分之一**。
- 而人类有文字的历史，大概是六千年。你此刻看到的那一行步数，在接下来的六千年里，变化不会超过屏幕的宽度。

## 你会看到什么

**前 29 天**，页面是全屏的倒计时（[现在就去看](https://catchagrenade.github.io/hanoi-64/)）。它一秒钟都没有在假装：那是在等一个所有人都能同时看见的开场。

**2026 年 10 月 24 日 00:00:00 UTC**，倒计时层淡出，HUD 上的"等待启动"变成"已移动步数"。第一秒，最小的那片盘子从 A 挪到 B。

接下来——

```
第 1 秒    盘 1：A → B
第 2 秒    盘 2：A → C
第 3 秒    盘 1：B → C
第 4 秒    盘 3：A → B
...
第 2⁶³ 秒  盘 64：第一次移动
```

前 30 秒你会觉得它很勤快。前三分钟也还行。然后你会发现，最底下那几片盘子，从你打开页面那一刻起就没动过 —— 而且在你关掉页面之前，也不会动。

**最底下那一片，将在 2923 亿年后才第一次离开 A 柱。**

如果你等得到那一天，请记下这一幕：那一刻的塔，和 2923 亿年前的那个瞬间，**逐位完全相同**。整个系统里没有任何一个字节发生可分辨的改变。你无法从这一帧里看出那一步到底走没走。

它比沥青实验更沉默。昆士兰大学那滴沥青，1927 年至今滴了九滴 —— 至少它是真的在滴，只是人活不够长。而这个实验是：**慢，且不可观测。** 你即使活到那一天，看到的画面和今天一模一样。

## 一个技术上的老实交代

这个页面**不累加**。它没有一条一直在跑的计数线，也不把状态存在任何地方。

每一帧，它只做一件事：

```js
步数 = (此刻的系统时钟 − 2026-10-24T00:00:00Z) / 1000
```

然后从这个数字**反推**整个塔的样子。

这意味着：

- 你的标签页在后台被浏览器降频、你的笔记本睡了两个月、你的浏览器崩了十次、你把网页关了三年 —— **都不会算错一步**。重新打开的那一刻，它会平静地告诉你现在应该是第几步，然后接着往下走。
- 没有任何服务器在运行这个实验。GitHub Pages 只是安静地托管着一份 HTML。这个实验真正发生的地方，是**每一个访客的浏览器**，以及那台机器的系统时钟。
- 所以，哪怕这个仓库被封存、这个域名消失、写下这段代码的人早已不在 —— 只要那份 HTML 还有一处副本，只要曾有人把 2026 年 10 月 24 日这个坐标告诉了后来的人，**任何人在任何一年打开它，都会得到一个诚实的数字。**

这个实验不需要被持续观看才能成立。它只需要被记住一次。
